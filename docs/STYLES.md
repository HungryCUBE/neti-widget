# Стили виджета

Стиль — это один JSON-файл в `app/src/main/assets/themes/`. Галерея в приложении и выбор стиля
строятся по этим файлам сами: положил файл — стиль появился. Код трогать не нужно.

Если для стиля нужен свой шрифт, его кладут рядом: `app/src/main/res/font/имя.ttf` или
`app/src/main/assets/fonts/имя.ttf` (только шрифты с открытой лицензией, OFL — текст лицензии в
`assets/licenses/`). Если шрифта нет — будет системный, сборка не падает.

Принципиально новая идея (не «другие цвета и шрифты», а другое расположение элементов) —
это новая раскладка: файл в `render/layout/` и одна строка в `Layouts.kt`.

## Как попросить новый стиль

Одной фразой, например:

> Сделай стиль «Frutiger Aero»: раскладка glass, фон — голубое небо с бликом, стеклянная капля
> вместо минут, глянцевый прогресс, шрифт Nunito.

Этого хватает: всё остальное — в схеме ниже.

## Пример: стиль на 15 строк

Стиль может взять всё у другого через `extends` и поменять только нужное:

```json
{
  "schemaVersion": 1,
  "id": "terminal-amber",
  "name": "Терминал янтарный",
  "extends": "terminal",
  "palette": {
    "text": "#FFC66D",
    "secondary": "#E0A040",
    "muted": "#7A5A2A",
    "accent": "#FFC66D",
    "track": "#3D2E14"
  }
}
```

## Как устроен файл

Все размеры — в dp **для стандартного виджета 4×2 (316×168)**. Как они меняются на других
размерах, решает движок (см. «Адаптивность»), стилю об этом думать не нужно.

Склейка: сначала общие умолчания `assets/engine/defaults.json` (тексты вроде «Далее · …»,
иконки), потом стиль из `extends`, потом сам файл. Объекты сливаются, строки и списки заменяются,
`null` удаляет поле.

### Верх файла

| Поле | Что это |
|---|---|
| `schemaVersion` | всегда `1` |
| `id` | латиницей: `glass`, `terminal-amber`. По нему виджет помнит свой стиль — не менять |
| `name` | название в галерее |
| `extends` | id стиля, от которого брать всё незаданное |
| `order` | место в галерее (меньше — раньше) |
| `layout` | раскладка: `glass`, `clean`, `ring`, `terminal`, `tonal`, `paper`, `dots`, `retro`, `tags` |
| `sizes` | какие формы стиль поддерживает: `compact` (2×2), `standard` (4×2), `large` (4×4 со списком пар). Без `compact` на узком виджете рисуется уменьшенный обычный вид, без `large` — нет списка пар |

### Цвета (`palette`)

Именованные цвета; их имена потом пишутся как `"@имя"`. Цвет можно написать так:

- `"#RRGGBB"`, `"#AARRGGBB"` (прозрачность впереди, как в Android), `"#RGB"`, `"transparent"`;
- `"@text"` — другой цвет палитры;
- `"@dynamic.accent1_600"` — системный цвет Material You (accent1–3, neutral1–2, оттенки 0…1000), Android 12+;
- `"@wallpaper.primary"` / `secondary` / `tertiary` — цвета обоев;
- `"@photo.dominant"` / `light` / `dark` — цвета своего фото (см. «Своё фото»);
- прозрачность после косой черты: `"@text/50%"`, `"#FFFFFF/0.2"`;
- запасные варианты через `|`: `"@wallpaper.primary | @dynamic.accent1_500 | #4B5BFF"` —
  берётся первый доступный. Последний вариант должен быть обычным цветом.

В превью и на скриншотах «живые» цвета не берутся — всегда запасной цвет, как в макете.

Какие имена нужны, зависит от раскладки (таблица ниже). Почти всем нужны `text`, `secondary`,
`muted`, `accent`, `track`, `surface`.

### Фон (`background`)

```json
"background": {
  "radius": 30,
  "clip": false,
  "layers": [ … ],
  "border": {"width": 1, "color": "@border"},
  "highlights": [ … ],
  "shadow": {"color": "#40000000", "blur": 12, "dy": 4}
}
```

Слои рисуются по порядку, снизу вверх. У любого слоя может быть `"when": "widget"` или
`"preview"` — только на рабочем столе или только в превью.

| Слой | Поля |
|---|---|
| `solid` | `color` |
| `linear` | `angle` (как в CSS: 90 — слева направо, 180 — сверху вниз) или `from`/`to` (`[x, y]` в долях), `stops`, `opacity` |
| `radial` | `center` `[x, y]` в долях, `radius` в долях от `radiusOf` (`diagonal`, `width`, `height`, `min`), `stops`, `opacity` |
| `mesh` | `points`: `[{"x", "y", "radius", "color"}]` — мягкие цветные пятна |
| `wallpaperMesh` | то же, по умолчанию из цветов обоев; можно задать свои `points` |
| `image` | `src` — картинка в папке стиля (`assets/themes/…`), `fit`: `cover`/`contain`/`stretch`, `opacity` |
| `photo` | своё фото, `fit`, `opacity` |
| `rules` | горизонтальные линейки: `offset`, `step`, `width`, `color` |
| `line` | одна линия: `x` (вертикальная) или `y`, `width`, `color` |
| `band` | наклонная полоса (для подложки превью): `x` в долях, `width`, `angle`, `pivot` |

`stops` — `[{"color": "#fff", "at": 0}, {"color": "#000", "at": 1}]` или коротко `["#fff", "#000"]`.

`clip: true` — слои рисуются прямоугольниками внутри скруглённой маски (нужно для линеек «Тетради»).

`border.color` — цвет или градиент-объект (`{"type": "linear", "angle": 180, "stops": […]}`), так
делается хромовая рамка. `highlights` — внутренние блики: `{"type": "innerStroke", "width", "inset",
"color"}` и `{"type": "gloss", "height": 0.5, "inset", "color"}` (глянцевая полоса сверху).
`shadow` — тень карточки; на рабочем столе ей нужно место: `adapt.widgetInset` ≥ `blur`.

### Текст (`typography`)

Роли: `header` (шапка), `title` (крупное название), `details` (строка под названием), `next`
(строка «Далее» и список пар), `counter` (цифры отсчёта). Раскладки берут и дополнительные роли
(см. таблицу раскладок). `defaults` — общее для всех ролей.

```json
"title": {
  "font": "manrope", "size": 26, "weight": 800, "letterSpacing": -0.02, "lineHeight": 1.15,
  "color": "@text",
  "fill": {"type": "linear", "angle": 180, "stops": ["#FFFFFF", "#9AA4B0", "#FFFFFF"]},
  "textShadow": {"color": "#40000000", "blur": 2.5, "dy": 0.8, "when": "widget"},
  "uppercase": false, "tabular": false, "underline": false,
  "base": "header",
  "align": "end"
}
```

- `font` — имя файла шрифта без `.ttf`; `system`, `serif`, `monospace` — системные.
- `weight` — 1…1000 (для вариативных шрифтов — точное значение оси wght).
- `letterSpacing` — в em, `lineHeight` — множитель размера.
- `fill` — градиент вместо цвета (хромовый текст).
- `base` — роль, от которой берутся незаданные поля.
- `align` — только для `counter`: `start`, `center`, `end`.

### Отступы (`spacing`)

`top`, `side`, `bottom` — внутренние отступы карточки (по умолчанию 16/18/14).
Мелкие промежутки внутри раскладки — в `metrics`.

### Числа раскладки (`metrics`)

Размеры, которые придумала раскладка: диаметр кольца, иконка и т. п. У каждой раскладки свои
имена и значения по умолчанию (таблица ниже).

### Прогресс (`progress`)

```json
"progress": {"type": "glossy", "height": 10, "radius": 5, "track": "@track", "fill": {"type": "linear", "angle": 90, "stops": ["#7FD6FF", "#1E88E5"]}, "glow": {"color": "#801E88E5", "blur": 6}, "gloss": 0.6, "minFill": 6}
```

| `type` | Что это | Свои поля |
|---|---|---|
| `line` | тонкая полоса | `height` (4), `radius` |
| `thick` | толстая полоса | `height` (8) |
| `striped` | полоса с диагональными полосками | `block` — шаг полосок |
| `glossy` | глянцевая полоса | `gloss` — сила блика 0…1 |
| `dots` | ряд точек | `height` — диаметр, `step`, `max`, `current` — цвет текущей точки |
| `blocks` | блоки как в Win95 | `block`, `gap`, `inset`, `frame: "bevel"` |
| `ring` | кольцо (в раскладке `ring`) | `width`, `cap`: `butt`/`round` |
| `text` | символами в консоли | `glyph`, `max`, `min`, `role`, `current` — цвет процента |

Общие: `track` и `fill` (цвет или градиент), `minFill` — минимальная видимая длина, `glow` — свечение.

### Отсчёт (`counter`)

`type`: `text` — просто цифры (шрифт и цвет — роль `counter`), `orb` — цифры в стеклянной капле
(`fill` — цвет или градиент капли, `track` — ободок, `gloss`, `padding`), `ring` — цифры в кольце
(`fill` — дуга, `track`, `width`, `padding`).

### Тексты (`strings`)

Шаблоны с подстановками. Виды:

- `"Далее · {next}"` — строка. Если какого-то значения нет (нет аудитории и т. п.), строки нет целиком;
- `["{room}", "{type}"]` — части через « · », пустые пропускаются;
- `{"parts": [...], "sep": " | "}` — то же со своим разделителем;
- `{"first": ["{room}", "{numLabel}"]}` — первый вариант, для которого всё есть;
- `{"one": "{n} пара", "few": "{n} пары", "many": "{n} пар"}` — по числу;
- `"{@другойКлюч}"` — вставить другой шаблон.

Фильтры: `{group|lower}`, `{type|cap}` (с большой буквы), `{dayLabel|short}` (до запятой), `|upper`.

Значения: `group`, `week`, `status` («Сейчас», «Перемена»), `headline` («2 пара · практика»),
`title`, `dayLabel` («Сегодня», «Завтра»), `message`, `num`, `num2` («02»), `numLabel` («2 пара»),
`type`, `typeShort`, `room`, `subgroup`, `start`, `end`, `until` («до 11:40» / «в 12:00»),
`next`, `nextStart`, `nextEnd`, `nextRoom`, `nextType`, `nextTypeShort`, `nextNum`,
`m` (минуты числом), `minutes` («34 мин»), `prefix` («ещё» / «через»), `duration` («2 ч 05 мин»),
`percent`, `cdUnit` («мин», только во время отсчёта), `phaseTitle` («Идёт пара»…).

Общие тексты лежат в `assets/engine/defaults.json`; стиль может переопределить любой.

### Флаги (`flags`)

Включают поведение раскладки: `stack`, `chip`, `nextShort`, `badgeCounter` — см. таблицу.

### Иконки (`icons`)

```json
"icons": {
  "color": "#FFFFFF",
  "slots": {"lesson": "book", "break": "coffee", "day": "calendar", "window": "my-icon"},
  "byType": {"лаб": "flask", "пр": "pencil"},
  "custom": {
    "my-icon": {"paths": ["M4 4h16v16H4z"], "viewBox": 24, "stroke": 2},
    "pixel-icon": {"pixels": [[1, 2, 14, 13, "#000000"]], "grid": 16}
  }
}
```

Встроенные: `book`, `pencil`, `flask`, `coffee`, `calendar` (Lucide). `byType` — по началу
сокращённого типа пары.

### Список пар на большом виджете (`agenda`)

`marker` (символ текущей пары, без него — точка), `text`, `muted`, `accent`, `pastAlpha`,
`rowHeight`, `rowSize`, `headerSize`, `twoLine` (строки в две строчки, если хватает места),
`maxGrow`, `fontGrow`.

### Размеры (`adapt`) и варианты (`variants`)

`adapt` обычно не нужен. Самое полезное:

| Поле | По умолчанию | Что это |
|---|---|---|
| `minWidth` | 300 | насколько можно «сузить» рисунок при увеличении: меньше — крупнее текст на высоких виджетах, но раньше обрезаются длинные названия |
| `maxScale` | 1.8 | максимальное увеличение |
| `minScale` | 0.85 | максимальное уменьшение на совсем маленьких виджетах |
| `widgetInset` | 0 | прозрачный отступ на рабочем столе (Win95 — 8, чтобы Android 12+ не срезал углы окна) |
| `compactBelow`, `shortBelow`, `largeFrom` | 230, 140, 250 | границы форм в виртуальных dp |

`variants` — что поменять в стиле на конкретной форме: `short` (низкий), `compact` (2×2),
`large` (4×4). Внутри — любые поля этого же файла:

```json
"variants": {
  "compact": {"metrics": {"ringDiameter": 52}, "typography": {"title": {"size": 17}}, "flags": {"stack": true}}
}
```

## Свой стиль из файла (импорт)

Интерфейса пока нет, но загрузчик готов: `Styles.import(context, json, fonts)` проверяет файл тем же
кодом, что и встроенные, и при успехе кладёт его в `files/themes/` (шрифты — в `files/themes/fonts/`).
Ошибки возвращаются списком, стиль с ошибками не сохраняется. Занять id встроенного стиля нельзя.

Своё фото для слоя `photo` и цветов `@photo.*` — файл `files/theme_photo.jpg` (выбор фото в
интерфейсе — следующий этап).

## Ошибки в файле

Файл проверяется при загрузке. Ошибка — стиль не появляется в галерее, а виджет с этим стилем
рисуется стилем по умолчанию (если и его нет — встроенным запасным). Текст ошибки — с файлом и полем:

```
glass.json: palette.surface: неверный цвет «#GGG» (нужно #RRGGBB или #AARRGGBB)
glass.json: неизвестное поле «colr» в typography.title — опечатка или поле из другой версии схемы
glass.json (вариант compact): typography: нет роли «header»
```

Ошибки встроенных файлов пишутся в «Отчёт об ошибке» в настройках. Тест `ThemeFilesTest` проверяет,
что каждый файл в `assets/themes` читается, ссылается на существующую раскладку и шрифты.

## Адаптивность

Один механизм в движке (`render/Adaptive.kt`), все стили получают его сами.

1. **Масштаб.** Стиль описан для 4×2 (316×168) и 2×2 (150×150). Если виджет больше, весь рисунок
   увеличивается: шрифты, отступы, скругления, кольца, точки, прогресс, иконки — вместе, как одна
   картинка. Насколько — решает ширина (по ширине должно остаться не меньше `minWidth`) и высота
   (должна влезать карточка). На стандартном 4×2 масштаб ровно 1 — виджет такой же, как был.
2. **Форма** по размеру, уже без масштаба: `compact` (узкий, 2×2), `short` (низкий — второстепенные
   строки убираются раньше названия), `large` (высокий — под карточкой список пар дня).
3. **Лишнее место** на высоком виджете забирает список пар: если хватает — строки в две строчки
   (время окончания, тип, аудитория), дальше строки растягиваются и шрифт растёт. Если места мало —
   сначала пропадают прошедшие пары, потом последние («и ещё 2 пары»).
4. **Меньше 2×2** — рисунок чуть ужимается (не больше чем до `minScale`), дальше раскладки сами
   убирают детали. Название пары сжимается последним.

Почему так, а не иначе:

- **Только пропорциональное масштабирование** не работает: 4×4 — это квадрат, а карточка 4×2
  вытянута. Растянуть её на квадрат — либо гигантский шрифт и обрезка по ширине, либо пустая
  половина. Поэтому масштаб считается по ширине, а высоту занимает список пар.
- **SizeMode.Responsive (набор брейкпоинтов)** не подходит, потому что виджет — картинка. Responsive
  рисует только под заданные размеры и растягивает ближайший — картинка выходит размытой или
  искажённой. Остаётся `SizeMode.Exact`: картинка рисуется под точный размер × плотность экрана
  для каждого размера, который сообщил лаунчер (портрет и ландшафт).
- **Отдельная вёрстка под каждый размер в каждом стиле** — 9 стилей × 4 размера, и каждый новый
  стиль надо было бы делать 4 раза. Здесь стиль описывается один раз, а если на каком-то размере
  нужно своё поведение — это пара полей в `variants`.

Хорошие виджеты (Google, Apple, Nothing) делают так же: на большом размере тот же вид, крупнее,
плюс больше информации (список, а не пустое место).

Размер берётся из `LocalSize` (Glance, режим Exact), если его ещё нет (виджет только что добавили) —
стандартный 4×2. При изменении размера (`onAppWidgetOptionsChanged`) виджет перерисовывается сразу.
Картинка ограничена по памяти: все картинки виджета вместе не больше полутора экранов
(4 байта на пиксель), при нехватке разрешение понижается, а не падает.

## Аудит: что было в коде и что теперь в JSON

До переделки все 9 стилей жили в Kotlin: объект `Styles` (цвета, шрифты, размеры) и по функции
на раскладку в `WidgetRenderer.kt`, где было зашито ещё много «стилевого». Папки `assets/themes`
не было. Теперь:

| Что | Где было | Где теперь |
|---|---|---|
| Цвета палитры, скругление, отступы, шрифты ролей | `Styles` в Kotlin | `palette`, `background.radius`, `spacing`, `typography` |
| Цвета внутри раскладок: плашка и счётчик «Стекла», белый чип и иконка Material, белый текст бейджей НЭТИ, серый `#404040` списка Win95, цвета рамок Win95 | константы в функциях раскладок | `palette` (`pill`, `chip`, `bevel*` …), роли текста, `agenda.muted` |
