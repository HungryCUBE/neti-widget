# Макеты новых стилей

Статичные копии досок с холста дизайна. Открываются в браузере, всё нужное — в inline-стилях.

- 1 css px = 1 dp на Android, виджет 4×2 = 316×168 dp. Макеты показывают стандартный 4×2.
- Тексты, время и аудитории — пример. В виджете — настоящее расписание.
- Фон вокруг карточки — пример обоев. Сам стиль — только карточка 316×168.
