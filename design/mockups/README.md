# Референсы дизайна

Статичные копии досок с холста дизайна, открываются в любом браузере.
Это источник истины для внешнего вида: все размеры, цвета, градиенты и шрифты — в inline `style="…"`.

- 1 css px = 1 dp на Android. Виджет 4×2 = 316×168 dp.
- Тексты, время, аудитории, группа «ФМА · ЭМ-63» — только пример. В приложении реальные данные и группа, которую выбрал пользователь (любая группа любого факультета).
- Фон вокруг виджетов — пример обоев, сам стиль — только карточка виджета.
- На макетах приложения светлая и тёмная тема рядом.
- Шрифты подключены с Google Fonts; в приложении — локальные файлы в `res/font`.
