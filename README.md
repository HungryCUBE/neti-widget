# Расписание НЭТИ — виджет

Виджет для Android, который показывает на рабочем столе расписание пар студентов НГТУ НЭТИ (Новосибирск):

- текущая пара: название, тип (лекция / практика / лабораторная), аудитория, сколько осталось до конца;
- следующая пара;
- прогресс текущей пары;
- выбор своей учебной группы — расписание подтягивается под неё;
- 9 стилей оформления на выбор.

> **Проект в разработке.** Готовых сборок пока нет.

## Неофициальный проект

Это **неофициальное** приложение. Оно не связано с НГТУ НЭТИ, не одобрено университетом и не является частью приложения YourNETI.
Расписание берётся с публичной страницы [«Расписание занятий»](https://www.nstu.ru/studies/schedule/schedule_classes) на сайте nstu.ru. Вход в личный кабинет не нужен, приложение не запрашивает логины и пароли.

Если расписание в виджете расходится с сайтом, верным считается сайт университета.

## Установка

1. Откройте на телефоне страницу [Releases](../../releases) этого репозитория.
2. Скачайте файл `.apk` из последнего релиза.
3. Откройте скачанный файл. Если Android попросит, разрешите установку из этого источника (браузера или файлового менеджера).
4. Нажмите «Установить».
5. Долгое нажатие на пустом месте рабочего стола → «Виджеты» → найдите «Расписание НЭТИ» и перетащите на экран.
6. В настройках виджета выберите свою группу и стиль.

## Как собирается

APK собирается автоматически в GitHub Actions при каждом изменении кода, ничего устанавливать на компьютер не нужно.
